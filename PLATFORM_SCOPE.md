# ShadowKite Frontend — Angular

Ce dépôt contient uniquement le socle Angular initialisé pour l’interface web de ShadowKite. Il ne contient pas encore les écrans métier, les appels API ni les templates visuels définitifs.

## Responsabilité

Le frontend Angular prendra en charge l’accueil public, l’authentification côté interface, le tableau de bord, les formulaires guidés du profil et du CV, l’éditeur de portfolio, l’aperçu, la page publique responsive et les intégrations nécessaires avec l’API Laravel.

## Tâches principales du frontend

- [ ] Mettre en place la structure des routes et des layouts.
- [ ] Intégrer les maquettes Figma sans inventer de composants avant validation design.
- [ ] Construire l’accueil, l’inscription, la connexion et la récupération de compte.
- [ ] Construire le tableau de bord et les écrans profil, CV et portfolio.
- [ ] Ajouter les formulaires, validations, messages d’erreur et états de chargement.
- [ ] Intégrer l’aperçu du CV, la page publique et les actions de partage.
- [ ] Préparer le responsive, l’accessibilité, les tests et la mise en ligne Vercel.
- [ ] Reporter les tâches transversales 1 à 80 dans `PROJECT_TASKS.md` et cocher uniquement les livrables réellement terminés.

## Socle initialisé

Le projet est généré avec Angular CLI, TypeScript, routage Angular et styles SCSS. Les dépendances ne sont pas installées par cette initialisation afin de laisser l’équipe choisir son mode d’installation et ses versions verrouillées.

## À ne pas faire dans cette initialisation

Ne pas développer les fonctionnalités métier, ne pas créer les templates Figma, ne pas connecter de données réelles et ne pas ajouter de design définitif avant validation du projet Figma.
